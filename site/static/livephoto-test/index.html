判读说明与限制
  • 签名：JPEG / PNG / GIF / WebP / BMP 的前几个字节是确定的；HEIC/HEIF、MOV/MP4 属于 ISO BMFF，要看 ftyp 品牌与 box 结构。
  • HEIF 的 hvc1 / grid 是图片 item，不是视频帧；只有 moov/trak/mdia 里 hdlr = vide 的轨道才算视频轨道。
  • 字节命中是启发式：Exif、com.apple.quicktime.content.identifier、still-image-time、LivePhoto / MotionPhoto 等标记只说明扫描范围内出现过这些字节。没有命中不代表不是实况照片。
  • UUID 候选不等于配对已证实：它只说明字节层面出现了类似 UUID 的内容。
  • 本页不解析完整 EXIF / MakerNote，也不解析 HEIF 的 iloc 数据位置。
  • 预览失败（尤其是 HEIC 或 HEVC 视频）只说明浏览器没能解码，不能据此认定文件里没有图片或视频。
  • 大文件只读取有限字节：结构解析最多 1 MiB，原始字节扫描最多 7 MiB（单文件合计 8 MiB）。该预算只约束结构与标记检查；浏览器为预览解码可能额外读取文件，不计入这 8 MiB。超出范围的标记不会被发现，页面会写明本次实际扫描范围。
  • 结构问题会区分两类：畸形（box 声明长度不合法、头不完整等，会停止该层解析，不再用于推导轨道）和读取限制（预算、box 数量、层深上限，只说明没读完）。
  • 预览信息（kind / status / 尺寸 / 时长 / error / timeout）会写入每文件 JSON，并随加载事件刷新；复制和下载会带上当前状态。
